# Исследование влияния изменения параметра при обучении модели на итоговый результат

## О проекте

Практическая работа по курсу Physical AI: исследование того, как изменение
параметров обучения модели PandaPickCube влияет на итоговый результат.
Модель обучается методом reinforcement learning (PPO из RSL-RL) в среде
MuJoCo Playground. Поведение модели задаётся не кодом правил, а
конфигурацией обучения: конфигурация → обучение → веса → поведение.

**Мой выбор параметра:** `box_target = 4` (усиление основной компоненты
награды «близость куба к цели» в 5 раз). Остальные эксперименты выполнены
в рамках курса и приведены для сравнения.

## Цель работы

Пройти полный цикл эксперимента: гипотеза → изолированное изменение →
обучение → инференс → сопоставление с гипотезой. Проверить, как изменение
веса компоненты награды влияет на две метрики качества:

- **mean_reward** — метрика оптимизации: то, что максимизирует PPO.
- **SR** — метрика выполнения задачи: доля эпизодов из 10,
  в которых куб оказался в пределах 0,05 м от цели.
